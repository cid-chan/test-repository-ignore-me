Round trip complete

This page is a static file in a GitHub repository. It reached your browser through the whole deployment path.

  1. A push landed on main in the client repository.
  2. GitHub posted to https://f441.net-up.de/gh-webhook, signed with the row's webhook secret.
  3. The receiver matched the secret, then ran f441ctl deploy round-trip-test my-container.
  4. f441 pulled the repository with the machine's deploy key into /srv/repo inside the Incus machine.
  5. Podman applied docker-compose.yml in that machine and published port 80.
  6. nginx on the forwarding machine proxied round-trip-test.f441.net-up.de to 10.40.0.58:80.
